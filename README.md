# Updated BLEDOM Web Controller

Edited for better UI and pairing system (supports more of those cheap bluetooth led strips from aliexpress)

-----
Supports:
* Better connection on WebBT by showing all devices
* (Half) Accurate colors for 5050 RGB Strips
* Live change brightness
* Pick your own color 
* Preset effects (with color preview/scroll) <- some effects not supported on all devices
* Live change effect speed
* More modern UI
